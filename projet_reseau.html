À propos du projet

Description & Objectifs

📋 Contexte

L'objectif est de simuler une infrastructure réseau d'entreprise complète avec Cisco Packet Tracer.

🎯 Objectifs

  • Concevoir une topologie réseau LAN
  • Configurer routeurs et switches Cisco
  • Mettre en place un plan d'adressage IP
  • Tester la connectivité (ping, traceroute)
  • Simuler le trafic réseau

⚙️ Fonctionnement

La topologie inclut un routeur central, des switches de distribution et des postes clients. Chaque machine est configurée avec une adresse IP statique. La communication inter-réseau est assurée par les tables de routage du routeur.

📚 Ce que j'ai appris

  • Adressage IP et sous-réseaux
  • Configuration CLI Cisco (IOS)
  • Protocoles de routage
  • Modèle OSI en pratique
  • Dépannage réseau
